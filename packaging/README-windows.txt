Porsche Unleashed (Rust port) - Windows x64

Start: PorscheUnleashed.exe
The game data is the "game" directory beside the executable; NFS5_GAME_PATH overrides it.

Requirements: Windows 10 or newer, a DirectX 12 or Vulkan capable GPU driver.
The first run may show a Windows Firewall prompt asking for network access: network games use
UDP port 1106 - allow it on private networks if you want to play over the LAN / internet.

Saves and settings: %APPDATA%\PorscheUnleashed (NFS5_SAVE_DIR overrides).
