# Controls

**English** | [Русский](../ru/controls.md)

The defaults are the original's. Keys and gamepad buttons can be changed in the game's own options
(Options → Controls). Gamepads: the left stick steers, the triggers are throttle and brake, Start pauses,
Select looks back; force feedback is used where the system and the pad support it.

## Driving

| Key | Action |
|---|---|
| ← → | steer |
| ↑ | throttle |
| ↓ | brake / reverse |
| Space | handbrake |
| A / Z | shift up / down |
| R | put the car back on the track |
| H | horn |
| L | headlights |
| W / E | left / right turn signal |
| T | hazard lights |
| Q | abort the race |

## View and HUD

| Key | Action |
|---|---|
| C | next camera |
| B | look back |
| Y / I / U | look left / right / forward |
| F2 / F3 / F4 | rotate the camera clockwise / stop / counter-clockwise |
| F5 | HUD on / off |
| F6 | rear-view mirror on / off |
| F7 | map on / off |
| F8 | HUD transparency |
| 1 / 2 | cycle the HUD / the map |
| F9 / F10 | music / sound effects |
| P | pause (Enter resumes, Esc returns to the menu) |
| F1 | pause menu |

## Menus

Arrows move between rows and change values, **Enter** confirms, **Esc** goes back. The mouse works as in the
original.
