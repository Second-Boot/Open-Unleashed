# Управление

[English](../en/controls.md) | **Русский**

Раскладка по умолчанию — как в оригинале. Клавиши и кнопки геймпада можно переназначить в настройках самой игры
(Опции → Управление). Геймпад: левый стик — руль, курки — газ и тормоз, Start — пауза, Select — взгляд назад;
обратная связь работает там, где её поддерживают система и геймпад.

## Езда

| Клавиша | Действие |
|---|---|
| ← → | руль |
| ↑ | газ |
| ↓ | тормоз / задний ход |
| Пробел | ручной тормоз |
| A / Z | передача вверх / вниз |
| R | вернуть машину на трассу |
| H | сигнал |
| L | фары |
| W / E | левый / правый поворотник |
| T | аварийка |
| Q | прервать гонку |

## Вид и интерфейс

| Клавиша | Действие |
|---|---|
| C | следующая камера |
| B | взгляд назад |
| Y / I / U | взгляд влево / вправо / вперёд |
| F2 / F3 / F4 | вращать камеру по часовой / остановить / против часовой |
| F5 | интерфейс вкл / выкл |
| F6 | зеркало заднего вида вкл / выкл |
| F7 | карта вкл / выкл |
| F8 | прозрачность интерфейса |
| 1 / 2 | переключить вид интерфейса / карты |
| F9 / F10 | музыка / звуковые эффекты |
| P | пауза (Enter — продолжить, Esc — выйти в меню) |
| F1 | меню паузы |

## Меню

Стрелки — переход между строками и смена значений, **Enter** — выбор, **Esc** — назад. Мышь работает как в
оригинале.
