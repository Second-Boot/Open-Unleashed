# Управление

[English](../en/controls.md) | **Русский**

Раскладка клавиатуры по умолчанию — как в оригинале. Клавиши и органы управления геймпада можно переназначить
в настройках самой игры (Опции → Управление); «По умолчанию» возвращает раскладку выбранного устройства. Геймпад
работает только через эти назначения: выберите его в списке устройств и нажмите «По умолчанию». На стандартном
геймпаде (Xbox, PlayStation, Switch Pro) это современная раскладка: левый стик — руль, RT — газ и LT — тормоз
(оба аналоговые), A — ручник, B — взгляд назад, X — вернуть машину на трассу, Y — камера, RB / LB — передача
вверх / вниз, Start — пауза, L3 — сигнал, крестовина вверх — фары, влево / вправо — поворотники, вниз — аварийка,
правый стик — взгляд влево / вправо. Рули и другие устройства получают раскладку оригинала. В меню крестовина или
левый стик перемещают выбор, A — выбрать. Обратная связь работает там, где её поддерживают система и геймпад.
Клавиатура работает вместе с геймпадом: действие, назначенное на геймпад, отвечает и на свою клавишу по умолчанию,
если эта клавиша не назначена другому действию.

На стандартном геймпаде у диалогов гонки и панели повтора есть свои кнопки; они действуют только пока открыт диалог
или панель (не во время езды): крестовина / левый стик выбирают, A отвечает, B — назад.

| Экран | Геймпад |
|---|---|
| меню паузы и вопрос о выходе | крестовина выбирает, A отвечает, B — продолжить (на вопросе — «нет») |
| страницы итогов, сообщения | A закрывает страницу, как пробел; на сводке проваленной миссии Y — «ещё раз» |
| сохранение повтора | A сохраняет под введённым именем или под первым свободным «Replay1», «Replay2»…; B закрывает |
| вопрос «перезаписать?» | крестовина выбирает, A отвечает, B — «нет» |
| просмотр повтора | A пауза / воспроизведение, крестовина вправо / влево — скорость быстрее / медленнее, вверх — страницы итогов снова, вниз — с начала (сетевой повтор: предыдущая машина), X — сохранить повтор, B — выйти, Y — камера |

## Езда

| Клавиша | Действие |
|---|---|
| ← → | руль |
| ↑ | газ |
| ↓ | тормоз / задний ход |
| Пробел | ручной тормоз |
| A / Z | передача вверх / вниз |
| R | вернуть машину на трассу |
| H | сигнал |
| L | фары |
| W / E | левый / правый поворотник |
| T | аварийка |
| Q | прервать гонку |

## Вид и интерфейс

| Клавиша | Действие |
|---|---|
| C | следующая камера |
| B | взгляд назад |
| Y / I / U | взгляд влево / вправо / вперёд |
| F2 / F3 / F4 | вращать камеру по часовой / остановить / против часовой |
| F5 | интерфейс вкл / выкл |
| F6 | зеркало заднего вида вкл / выкл |
| F7 | карта вкл / выкл |
| F8 | прозрачность интерфейса |
| 1 / 2 | переключить вид интерфейса / карты |
| F9 / F10 | музыка / звуковые эффекты |
| P | пауза; в меню паузы стрелки выбирают, Enter отвечает (продолжить, ещё раз, выйти, фото-режим) |
| F1 | спрятать / показать меню паузы или страницу итогов, чтобы посмотреть на сцену за ними |

В конце гонки **пробел** закрывает страницы итогов одну за другой и выходит с последней.

## Фото-режим

Свободная камера в паузе или в повторе (кроме сетевых гонок: там пауза не останавливает гонку). Включается пунктом
**фото-режим** в меню паузы (на геймпаде: крестовиной до него, A) или клавишей **K** (на Windows и Linux также **F11**)
в меню паузы или в повторе. Пока он открыт, гонка или повтор стоят. В оригинальной игре его нет.

| Клавиатура / мышь | Геймпад | Действие |
|---|---|---|
| W A S D, Q / E | левый стик, LT / RT | движение, вниз / вверх |
| стрелки, правая кнопка мыши | правый стик | обзор |
| Z / X | LB / RB | наклон |
| колесо, `-` / `=` | крестовина вверх / вниз | приближение |
| Shift / Ctrl | L3 | быстрее / медленнее |
| Enter, пробел | A | сохранить снимок; `6` — его размер (1x, 2x, 4x окна) |
| H | Y | интерфейс игры |
| Tab, R | | подсказка, сбросить камеру |
| K, Esc, P, Backspace | B | выйти |

Снимки сохраняются в PNG в папку `Изображения/PorscheUnleashed` (`NFS_PHOTO_DIR` задаёт другую).

## Меню

Стрелки — переход между строками и смена значений, **Enter** — выбор, **Esc** — назад. Мышь работает как в
оригинале.
