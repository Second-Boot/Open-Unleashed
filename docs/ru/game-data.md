# Данные игры

[English](../en/game-data.md) | **Русский**

В движке нет ни одного файла оригинальной игры. Он читает данные **вашей копии** Need for Speed: Porsche Unleashed
и ничего в ней не меняет.

## Что нужно

Из установленной игры — из папки, где лежит `nfs5.exe`:

| Файл / папка | Обязательно | Зачем |
|---|---|---|
| `GameData/` | да | трассы, машины, физика, звуки |
| `FEData/` | да | меню, шрифты, тексты, ролики |
| `nfs5.exe` | нет | из него берутся таблицы для вступительных роликов (сам он не запускается); без него ролики пропускаются |
| `fe.txt` | нет | файл настроек оригинала; без него используются настройки по умолчанию |

## Где движок ищет данные

По порядку; используется первая папка, в которой есть и `GameData`, и `FEData`:

1. папка из переменной окружения `NFS5_GAME_PATH`;
2. `game/` рядом с программой (в архивах релизов есть пустая);
3. на macOS: `game/` рядом с `OpenUnleashed.app`, затем внутри приложения (`Contents/Resources/game`);
4. `~/Games/NFS-Porsche-Unleashed/game_info/data`, затем `~/Games/NFS-Porsche-Unleashed`.

Частая ошибка — лишняя вложенность: `game/data/GameData` вместо `game/GameData`.
